# 复核 — 一个入口·三档(+优化档)

人话:**快速=改完 AI 自跑;提交时 hook 自动;另三个你给路径 + 说「阶段」「大清理」或「优化」。** 机器供 scope,判断/批准留人。

三档 = `check.py` 三阶段档/检查档(速度×影响);优化档独立(非 check.py 阶段档,凭测量数据):

| 你说 | 机器跑 | 谁触发 |
|---|---|---|
| (默认) | ruff/compile(秒级);手动全档 `check.py quick` | 改完 AI 自跑;提交时 hook 自动 |
| **阶段** | `check.py stage`(承重档:依赖方向/身份/可逆性/双源/漂移/子agent材料) | 你喊 |
| **大清理** | `check.py cleanup`(全量·所有工具·最严格·多档) | 你喊 |
| **优化** | 埋点计时/内存快照(非 check.py 阶段档;专用 profiling 探针建成后登记 registry) | 你喊(功能跑通后) |

闸清单:`check.py list` 看阶段/工具与命令。契约闸 `rule-tool-contracts` 守"登记即接线":registry 声明的工具命令必须在 check.py 兑现,否则红=僵尸工具(写了没触发档=该删或该接)。

不变量(违则停):
- 时机=人(机器拿不到进度);承重=机器证据包(stage-packet/inventory/import-cycles/dup-symbol)辅助,非人眼单猜;放行批准=人(AI 提议+证据、闸红逼审);行为安全=测试。
- **绿闸 ≠ 架构无恙,只证 L4/L5**;L1–L3 工具够不到,靠人/agent 审。
- **拆分判据=连通度非行数**:拆前用一次性连通度探针或 import-cycles 证据辅助,最大连通块≥80%=内聚不拆(硬拆=造循环依赖);探针未被验证前不得沉淀成正式工具。
- 成本∝1/频率:per-commit 禁全仓扫;贵活只在大清理。

五层(审从上往下,上层没过别下层):
| 层 | 裁判 |
|---|---|
| L1 依赖方向/分层 | import-linter/import-cycles/encapsulation + 人定契约对不对 |
| L2 归属/双源 | def·class 名近似/词根碰撞(dup-symbol)；不同名或语义重叠→子agent对抗 |
| L3 契约/不变量 | 真测试(跑出来) |
| L4 死码/形状 | vulture/radon/import-cycles |
| L5 整洁 | ruff |

---

## 快速(默认·每次改完)
AI 改完自跑轻量检查;提交时 pre-commit hook 自动跑。无需你喊;不过别提交。

## 阶段检查(你喊「阶段」+ 路径)
机器:`check.py stage`。人/agent 审机器判不了的语义层,按**扰动 scope**(git diff+AST→待审面,确定性非察觉):
- 新跨包 import → L1 依赖方向(import-linter/encapsulation 守 + 人定契约对不对)。
- 新顶层 def 近名 / 盖既有能力 → L2 双源(dup-symbol + 扇入证据;近名+一死=删候选;不同名→finder→refuter);入口是否真薄(业务逻辑别混进 tools 入口)。
- 公共签名/返回变 · 碰 save·batch·幂等 → L3 真测试(幂等连调2次副作用=1、部分成功注入第N+1条可区分、返回结构可判别)。
- 新抽象(继承 ABC/注册分发/包装层)→ `code.index.md` §1 索三点证据。
- 四类全空(文档/局部 bugfix)→ 只机器档,不深审。审查量=扰动量。
审法:按亮面喂子agent对抗,finder→refuter(默认存疑)、逐条交一次一条、坐实才动手。
合 main:机器档全过 + 四档结论 + 死码/双源清单 + 放行 pending(待批)。

## 优化(你喊「优化」+ 路径;功能跑通后)
机器:埋点计时耗时降序 + 内存快照(专用 profiling 探针建成后登记 registry;此前用 `code.index.md` §2 的埋点数据)。
AI:按测量归因——最慢步骤在做什么/这工作必要吗/在重复吗/随什么涨——**方案从归因推出,无归因链的提案不上桌**(缓存/并发/惰性加载等词只许作结论出现,不许作候选清单)。每项改动带前后对比数字,数字是裁判,无数字=没做。
边界:数量级与形态(接口里焊死的超线性/全量 vs 流式)在赌点/分叉时把关(AGENTS.md §2·§4),事后难改;优化档只管可测量的常数与资源(设计时管数量级,优化档管常数)。

## 大清理(你喊「大清理」+ 路径)
**铁律:大清理 = 所有工具全上、取最严口径、L1 依赖方向 → L5 整洁多档无死角,不挑档不减项。** 新增静态闸一律纳入 `cleanup`。
机器:`check.py cleanup`(全量·所有静态/类型/安全/测试闸;`check.py list` 看清单)。人/agent 再审 vulture/可达性判不出的语义死码:
- 每条「该删」grep 自验**全仓零 live caller**(无 `getattr`/`__all__`/字符串分发)→ finder→refuter 全局证伪 → 人裁才删。删码近不可逆,举证责任在发现方,**宁漏删不误删**。
- 弃用但仍 live 的旧路径(双源 SSOT)、注册表/反射僵尸、孤儿文件 → 同上证伪。
- 漂移红(超行/skip/白名单涨)、晋升/降级候选(扇入)→ **记待办,不自动改**。
产物:四档结论(逐条)+ 死码/双源/废弃清单(已删 or 放行登记:原因+可判定清除条件)+ 放行 pending(待批)。
