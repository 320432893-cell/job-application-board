# 命名约定（tier1，按需读；当可 grep 的意图信号）

触发：新增/改名符号时；写命名检查时读。

**铁律**：要写成强约束的命名约定,必须配现有机器检查兜底；未接线的名字只能当 grep/人工复核信号,不能宣称硬拦。名字会撒谎（状态变了没人改名）——这是 §code.index §5 否决 `# expires:` 标签的同一教训。

**分工**："有没有被用"靠 vulture/扇入从**真实用法**算（名字会骗、用法不骗），**别靠命名**；命名只标**用法看不出的意图**（私有/实验/废弃/探针）。

**唯一律**：同一顶层符号名（def/class）全仓应语义唯一——**新增前先 grep 查重（名 + 词根）**；机器对新增完全同名阻塞，对同词根只给复核信号，因为词根不足以证明同一能力。两者命中都要摆分叉交人裁（取代旧 X / 意外·边缘 / 备选·fallback / 删 / 确非同类），**禁静默另写并存**；存量仅在 cleanup 提示（流程细则见 §AGENTS §5，此处只声明约定、不复述）。

## §1 约定表（每条配 grep 用途 + 兜底检查）
| 命名 | 意图 | grep 用途 | 已接线兜底 |
|---|---|---|---|
| `_前缀` | 私有/模块内 | 找内部件 | 跨模块 `from X import _name` = 红 |
| `experimental_`/`_exp` | 流动前沿·勿依赖 | 找不稳定 API | 豁免稳定闸；晋升靠改名（AGENTS §4 流动前沿） |
| `_deprecated`/`_legacy` | 迁移中的旧实现 | **找该删的旧双胞胎** | grep/人工复核信号；接入 registry 工具前不宣称机器硬拦 |
| `probe_`/诊断件 | 只诊断·非生产 | 找探针 | 必带 `# lifecycle:` + 不可被 core import |
| `_stub_`/`_wip_` | 有意占位·待填 | 找占位 | grep/人工复核信号；git 年龄只作审查证据,接入 registry 工具前不宣称机器硬拦 |

## §2 "找占位/不用还留着" = 四信号叠（别单靠名）
1. vulture/扇入 → 确实没用（真实用法）；
2. `_stub_`/占位名 → 标"有意占位"（意图）；
3. git 年龄 → 老 stub=撒谎=rot、新=WIP 宽限；
4. 白名单 → "没用但有意留"的登记表**即占位清单**（带理由，grep 它就列全）。

## §3 落地
- 当前已接线兜底:ruff `N`(PEP8 命名形状) + `encapsulation`(私有/内部 import) + `dup-symbol`(顶层名字/词根碰撞)。语义相似不由词法工具定案，交子 agent 反驳审查；命名类新规则必须先接入 registry,再写规则;
- **只约束新代码**；存量旧名不强行大改名（违背"改便宜"），碰到再改、慢慢收敛（老项目小改优先局部一致）。
