# 求职申请管理看板

一个面向产品经理求职场景的可视化管理工具，用来统一管理投递进度、面试安排、Offer 对比和数据统计。

## 项目定位

这个项目不是通用招聘系统，而是一个聚焦个人求职管理的前端作品：

- 用看板方式管理不同申请状态
- 用日历和待办降低遗漏风险
- 用时间线展示单个岗位推进过程
- 用数据统计快速总结整体求职进展
- 用 Offer 对比与雷达图支持决策

适合作为产品经理面试作品集项目展示。

## 功能概览

### 1. 求职看板
- 按状态管理申请：待投递、已投递、笔试、面试中、Offer、已拒绝
- 支持拖拽修改状态
- 支持查看、编辑、删除申请
- 支持批量选中、批量改状态、批量删除

### 2. 搜索与筛选
- 关键词搜索：公司、岗位、城市、行业
- 多条件筛选：公司类型、城市、招聘类型、状态、行业
- 面试维度筛选：语言、形式、类型
- Offer / 可转正筛选
- 薪资区间筛选

### 3. 日历与提醒
- 日历集中展示截止日期、面试、Offer 答复时间
- 今日待办自动汇总关键节点
- 支持浏览器提醒开关
- 支持面试准备提醒

### 4. 冲突检测
- 面试时间冲突检测
- 面试与课程时间冲突检测
- 冲突信息在看板中高亮提示

### 5. Offer 决策
- Offer 对比表
- 自定义权重评分
- 雷达图对比决策维度

### 6. 过程展示与统计
- 时间线页：展示每条申请的推进过程
- 统计页：展示申请总数、状态分布、城市分布、Offer 数量等

### 7. 数据管理
- 导入 Excel / CSV
- 导出 Excel
- 快速录入助手：从 JD 文本提取公司、岗位、城市、薪资等信息

### 8. 快捷操作
- `Ctrl + N`：新建申请
- `Ctrl + F`：聚焦搜索
- `ESC`：关闭抽屉或清空选择
- `Delete`：删除已选申请

## 项目亮点

- 从产品视角定义核心流程，而不是只做 CRUD
- 把投递、面试、Offer 决策串成一条完整链路
- 兼顾展示层、交互层和数据管理层
- 适合作为“产品思维 + 落地能力”的面试作品
